# 선행연구와 이 프로젝트의 자리

2026-11-15 · 무엇이 이미 되어 있고, 무엇이 비어 있고, 우리가 어디를 맡는지.

읽은 깊이를 논문마다 표시한다. **[본문 일부]** 는 앞부분 약 40%만 읽었다는 뜻이고, **[초록]** 은 초록이나 발췌만 봤다는 뜻이다. 본문을 다 읽으면 이 문서를 고친다.

## 1. 가장 가까운 연구

### Wang & Saxena (2026), "Fake News, Real Crashes" — arXiv:2610.26438 [본문 일부]

조작된 뉴스로 LLM 거래 에이전트를 속이는 공격을 체계적으로 시험했다. 문제의식은 우리와 같다. 에이전트들이 같은 피드를 비슷한 정책으로 읽으면 조작된 글 하나가 모두를 같은 거래로 민다.

| | 이 논문 | EchoGuard |
|---|---|---|
| 과제 | 거래 결정 (매수·매도·보유와 수량) | 뉴스 판단 (강도·방향) |
| 시장·언어 | 미국 주식 15종목, 영어 | 한국 뉴스 100건, 한국어 |
| 주 평가 모델 | 1개 (다른 모델은 150회 보조 실험) | 5~7개를 같은 조건으로 |
| 모델 간 오류 상관 | 읽은 범위에서는 측정 없음 | 주 지표 |
| 통계 검정 | 읽은 범위에서는 없음 | 난이도 구간 내 순열검정, 부트스트랩 구간 |
| 여러 출처 대조 방어 | 시험하지 않음 | 가드 G4로 구현·평가 |
| 관점 | 공격 성공률 | 방어 성능 (재현율, 검토 비율) |

이 논문에서 가져오는 것:

- **내용만 보는 방어는 가짜와 진짜를 가르지 못한다**는 주장. 가를 수 있는 것은 출처 정보나 에이전트의 시장 상태뿐이라고 본다. 패널 일치도만 보는 G1이 왜 부족한지의 근거다.
- **여러 출처가 동의하는 것처럼 꾸민 공격**도 평균 61.6% 성공했다. 그래서 G4는 글의 개수가 아니라 서로 독립인 출처의 수를 세야 한다.
- 방어 성능을 **고정된 오경보율에서** 보고하라는 권고. 우리는 가드끼리 같은 검토 비율에서 비교한다.

### "SoK: Trading Agents or Market Crashers?" — arXiv:2609.19705 [본문 일부]

LLM 거래 에이전트 연구 15편을 보안 관점에서 정리했다.

- 15편 중 출처를 기록하거나 여러 출처의 대조를 요구하는 것은 **하나도 없었다**. 대조는 권고만 되고 구현되지 않았다.
- 군집 행동이 피해를 키운다고 서술하지만 **직접 측정하지는 않았다**.
- 다수결·토론 같은 집계는 잡음은 걸러도 겨냥된 오정보는 못 거른다고 본다.

우리가 맡는 빈칸이 여기서 나온다. 함께 틀리는 정도를 측정하는 것, 그리고 출처 대조 가드를 실제로 구현해 평가하는 것이다.

### TradeTrap — arXiv:2512.02261 [초록]

가짜 뉴스와 도구 탈취로 정보 모듈이 오염되면 포지션 집중, 거래 빈도 증가, 큰 낙폭이 나타났다.

## 2. 모델 획일화 측정

- Research Square rs-10928394 [초록]: 감독기관들이 획일화를 위험으로 꼽았지만 무엇을 어떤 데이터로 잴지는 정하지 않았다고 지적. 잔차 상관 통계는 공통 결과 항에 오염되므로 귀무 분포로 정규화한 지수를 제안. 우리 순열검정과 같은 문제의식이다.
- "Why Better Models Can Create Riskier Systems" arXiv:2609.04373 [초록]: 7개 LLM. 같은 오정보 환경에서는 오류가 완전히 상관된다.
- "Financial Stability Implications of Generative AI" arXiv:2510.01451 [초록]: LLM 에이전트는 군집이 최적일 때도 군집을 피했다. 위와 반대 방향의 증거다.
- Cheng, Hu, Li (2026), "When Machines Disagree" [초록]: 6개 LLM이 같은 헤드라인에 다른 판단을 낸다.

증거가 엇갈린다. 그래서 질문을 "쏠리는가"가 아니라 "어떤 입력에서 함께 틀리는가"로 잡는다.

## 5. 우리가 하지 않는 것

탈옥, 프롬프트 주입, 도구 권한 탈취, 사기탐지 모델 오염은 다루지 않는다. 기관과 연구팀이 이미 깊게 하고 있고, 혼자서 더할 것이 적다. 이 프로젝트는 **판단이 함께 틀리는 문제**에 머문다.

## 6. 이 프로젝트의 기여 (주장하려는 것)

1. 한국어 금융 뉴스에서 여러 회사 모델의 오류가 함께 움직이는지를, 난이도를 통제한 검정으로 측정한다.
2. 그 오류를 두 종류로 나눠 잰다. 글을 함께 잘못 읽는 것(오독)과, 조작된 글을 함께 믿는 것(오신).
3. 일치도, 출처 표기, 변형 탐침, 출처 대조 네 가지 가드를 같은 검토 비율에서 비교한다.

아직 결과가 없으므로 셋 다 계획이다.
