# 필터로 쓰기

EchoGuard의 본체는 가드다. AI의 답이 사람이나 다음 시스템으로 넘어가기 전에 걸러서, 의심스러운 것을 사람에게 넘긴다. 답을 고치지는 않는다.

`pipeline`은 그 가드가 얼마나 잘 잡는지 재는 실험이고, `filter`는 가드를 실제로 쓰는 창구다. 둘은 `guard.py`의 같은 함수를 부른다.

## 한 건 판정하기

```python
from echoguard.filter import screen

verdict = screen(
    outputs,                  # 모델 이름 → 그 모델의 반복 답들
    figure=-32.0,             # 글에 적힌 기준 지표의 값 (알 때만)
    primary_verified=True,    # 공시·정부 발표 원문을 실제로 확인했는가
    n_independent=1,          # 따로 확인해 준 독립 출처 수
)
verdict.decision   # "통과" 또는 "검토"
verdict.reasons    # 걸린 이유들
```

공시 숫자 한 건을 실제 모델에 묻고 판정하려면 `python -m echoguard.filter --numbers 공시.json`. API 키와 비용이 든다.

## 무엇을 보는가

| 검사 | 걸리는 경우 | 필요한 정보 |
|---|---|---|
| G0 입력 점검 | 옮겨 적은 숫자끼리 어긋난다 (이익인데 적자전환, 영업이익이 매출보다 큼, 공시일과 접수일이 다름 등). 걸리면 모델을 부르지 않는다 | 없음 |
| 응답 | 답을 내지 못한 모델이 있다 | 없음 |
| G1 답의 일치 | 모델들의 방향이 갈린다 | 없음 |
| G3 말 바꿔 다시 묻기 | 같은 숫자를 다른 말로 다시 물었더니 다수결이 바뀐다 | 말 바꾼 글에 대한 답 (호출 수 두 배) |
| G4b 출처 대조 | 1차 출처가 확인되지 않았고 독립 출처가 기준보다 적다 | 출처 확인 결과 |
| G6 근거 대조 | 근거가 지침과 어긋난 모델이 있다 | 글의 기준 지표 값 |

하나라도 걸리면 검토다.

## 판정 기록

`--numbers`로 판정하면 `data/audit/decisions.jsonl`에 한 줄씩 남는다. 판정, 걸린 검사와 이유, 모델 버전, 기준값, 지시문 해시가 들어간다. 입력 글은 저장하지 않고 해시만 남긴다. 이 폴더는 리포에 올리지 않는다.

```
python -m echoguard.audit summary data/audit/decisions.jsonl                     # 검토 비율, 걸린 검사, 사람이 아직 안 본 건
python -m echoguard.audit review  data/audit/decisions.jsonl <id> <검토자> 반려 "메모"   # 사람의 결정을 남김
python -m echoguard.audit verify  data/audit/decisions.jsonl                     # 기록이 고쳐지지 않았는지
```

각 줄에 앞 줄의 해시가 들어 있어서 중간을 고치면 드러난다. 파일 전체를 다시 쓸 수 있는 사람까지 막지는 못한다.

## 알아둘 것

- G0는 숫자끼리의 모순만 본다. 옮겨 적은 숫자가 원문과 같은지는 알 수 없다. 손실인데 변동률이 숫자로 적힌 경우도 걸리게 해 두었는데, 실제 공시가 그렇게 적는 경우가 있으면 잘못 걸릴 수 있다. 그때는 사람이 보고 넘긴다.

- 필요한 정보를 주지 않은 검사는 하지 않는다. 판정의 `checks`에 `ran=False`로 남는다. 검사를 하지 않은 것은 통과가 아니다. 출처 정보 없이 받은 "통과"는 답이 일치했다는 뜻일 뿐이다.
- 출처는 `source.verify_dart`가 확인한다. 공시 주소의 접수번호가 전자공시 목록에 있고 회사 이름이 같은지 조회한다(환경변수 `DART_API_KEY` 필요). 옮겨 적은 숫자가 원문과 같은지는 확인하지 않는다. 글에 붙은 출처 표기를 그대로 넘기면 G2와 같아져서 조작에 뚫린다.
- 답을 내지 못한 모델이 하나라도 있으면 검토다. 공급사 장애로 모델이 멈추면 모든 문서가 사람에게 넘어간다. 줄어든 패널로 조용히 통과시키지 않는다.
- 글 안에 숨긴 지시문을 모델이 따르면 답이 글의 숫자와 어긋나므로 G6에 걸린다. 기준 값을 모르는 글에서는 이 방어가 없다.
- G5(학습 가드)는 아직 필터에 넣지 않았다. 학습할 실제 응답이 없다.
- 기준값(일치 0.8, 출처 2곳)은 임시다. 가드의 실제 성능은 아직 재지 못했다. 이 필터의 "통과"를 근거로 실제 판단을 내려서는 안 된다.
