# 라벨링 가이드

`data/labels/news_labels.csv`에 뉴스 한 건을 한 줄로 적는다. 정답 라벨이 있어야 "일치했는데 틀린" 경우를 셀 수 있다.

## 작업 순서

1. **후보 모으기**
   - 종목 뉴스(70건): `python scripts/sample_candidates.py`가 2026-10-01 이후 잠정실적 공시에서 무작위로 140건을 뽑아 `data/candidates/disclosures.csv`에 쓴다. 전자공시 API 키(무료, opendart.fss.or.kr)가 필요하다. 이 스크립트가 안 되면 KIND(kind.krx.co.kr)의 공시 검색에서 "영업(잠정)실적"을 같은 기간으로 조회해 엑셀로 내려받는다.
   - 거시·정책 뉴스(30건): 한국은행, 기획재정부, 금융위원회, 산업통상자원부 보도자료 목록에서 같은 기간의 것을 위에서부터 고른다.
   - 출처 미확인 뉴스(30건, 위 100건에 포함): "단독", "~로 알려졌다", "업계에 따르면"으로 시작해 1차 출처가 없는 보도를 뉴스 검색으로 찾는다. 이 부분은 규칙으로 뽑기 어려워 직접 고른다. 고른 기준을 `label_basis`에 남긴다.
2. **엑셀에 적기**: `data/labels/labeling_template.xlsx`를 복사해 `내이름_filled.xlsx`로 저장하고 노란 칸을 채운다. 2행은 지어낸 예시다.
3. **변환과 검사**: `python scripts/xlsx_to_labels.py 내이름_filled.xlsx`. 빠진 칸이 있으면 줄 번호와 함께 알려 주고, 없으면 라벨 파일을 쓰고 구성 비율을 보여 준다.
4. **올리기**: `news_labels.csv`만 리포에 올린다. 사실을 뒤집은 글이 든 `perturbations.csv`와 채우는 중인 엑셀은 `.gitignore`에 있어 올라가지 않는다.

후보를 사람이 골라 담지 않고 규칙으로 뽑는 이유: 고르는 쪽의 취향이 표본에 섞이면 결과가 그 취향을 반영한다. 특히 AI가 후보를 고르면 채점 대상이 문제를 고르는 셈이 된다.

## 열 설명

| 열 | 내용 |
|---|---|
| item_id | `n001`부터 순서대로 |
| date | 기사 날짜 (YYYY-MM-DD). 패널 모델의 지식 기준일보다 뒤여야 한다 |
| type | stock(종목) 또는 macro(거시·정책) |
| source | 매체 또는 공시처 |
| url | 원문 주소. 원문 본문은 리포에 올리지 않는다 |
| title | 기사 제목 |
| summary | 직접 쓴 2~3문장 요약. 모델에는 이 요약을 넣는다. 수치·주체·날짜를 넣고 '호재', '충격' 같은 평가어는 쓰지 않는다 |
| intensity_true | 사건 강도 1~5 (아래 기준표) |
| direction_text | 주 정답. 글에 적힌 사실만으로 판단한 방향: -1 부정, 0 중립, 1 긍정 |
| direction_realized | 보조 정답. 공개 후 5거래일 시장조정 누적수익률의 부호, 절대값 1% 미만은 0 |
| difficulty | clear 또는 ambiguous |
| label_basis | direction_text를 그렇게 붙인 근거 한 줄 |
| source_verified | 공시·정부 발표처럼 1차 출처가 확인되면 1, 아니면 0 |
| n_independent_sources | 같은 사실을 따로 확인해 준 독립 출처의 수. 공시·정부 발표, 자체 취재로 확인한 주요 매체만 센다. 받아쓴 기사, 통신사 전재, 커뮤니티 글은 세지 않는다 |
| n_reports | 같은 내용을 실은 글의 수. 제목이나 핵심 문장으로 검색해 센다. 받아쓴 글과 전재도 센다. 5건 이상은 5. 항상 n_independent_sources 이상이어야 한다 |
| split | tune(설정용 60건) 또는 eval(평가용 40건). 스크립트가 채운다 |
| labeler | 라벨을 붙인 사람 |

## 강도 기준표

모델에 주는 지시문(`prompts/institutional_system.txt`)과 같은 기준이다. 한쪽을 고치면 다른 쪽도 고친다.

| 강도 | 기준 | 예 |
|---|---|---|
| 1 | 관측·전망·검토 보도. 확정된 조치나 수치가 없다 | "인수를 검토 중인 것으로 알려졌다" |
| 2 | 확정된 사실이지만 영향이 작다. 핵심 수치 변동 10% 미만, 또는 일정·대상이 불명확한 방침 | 영업이익 6% 증가 공시 |
| 3 | 확정된 사실이고 영향이 중간. 핵심 수치 변동 10% 이상 30% 미만, 또는 시행일·대상이 명시된 정책 발표 | 영업이익 18% 감소 공시 |
| 4 | 확정된 사실이고 영향이 크다. 핵심 수치 변동 30% 이상, 적자·흑자 전환, 핵심 산업이나 시장 전체에 적용되는 조치의 시행 | 영업이익 32% 감소 공시, 적자 전환 |
| 5 | 존속이나 거래 자체가 걸린 사건. 거래 정지, 상장폐지 사유, 부도·회생 신청, 자산 동결, 전면 금지 | 감사의견 거절로 거래 정지 |

- 핵심 수치는 영업이익의 전년 동기 대비 변동률이다. 영업이익이 없으면 매출, 수주·계약 뉴스는 직전 연 매출 대비 비율을 쓴다.
- 여러 등급에 걸치면 높은 쪽을 고른다.

숫자 기준을 넣은 이유: 2026-11-15 시험 호출에서 "영업이익 32% 감소 공시" 예문에 여섯 모델의 방향은 전부 일치했지만 강도는 3과 4로 반씩 갈렸다. 이전 기준표가 "공식 발표(3)"와 "대규모 실적 충격(4)" 양쪽으로 읽혔기 때문이다.

## 원칙

- direction_text는 느낌으로 붙이지 않는다. label_basis에 근거를 남길 수 없으면 그 뉴스는 뺀다.
- direction_text를 붙일 때 주가를 보지 않는다. direction_realized는 라벨을 다 붙인 뒤 스크립트로 채운다.
- 강도와 방향이 애매한 뉴스도 일부러 20% 정도 넣는다. 모델들이 갈리는 구간을 보기 위해서다. 이 경우 difficulty를 ambiguous로 적는다.
- 라벨은 모델 출력을 보기 전에 확정한다. 본 뒤에 고치면 실험이 오염된다.
