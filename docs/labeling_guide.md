# 라벨링 가이드

`data/labels/news_labels.csv`에 뉴스 한 건을 한 줄로 적는다. 정답 라벨이 있어야 "일치했는데 틀린" 경우를 셀 수 있다.

## 작업 순서

1. **후보 모으기** (출처 확인 여부가 뉴스 종류와 겹치지 않게 네 칸으로 나눈다)

   | | 출처 확인됨 | 출처 미확인 | 합 |
   |---|---|---|---|
   | 종목 | 50 (잠정실적 공시) | 20 | 70 |
   | 거시·정책 | 20 (정부·한국은행 보도자료) | 10 | 30 |
   | 합 | 70 | 30 | 100 |

   - 종목·확인됨 50건: `python scripts/sample_candidates.py`가 2026-10-01 이후 잠정실적 공시에서 무작위로 140건을 뽑아 `data/candidates/disclosures.csv`에 쓴다(2026-11-15 실행: 597건 중 140건). 전자공시 API 키(무료, opendart.fss.or.kr)가 필요하다. **목록 위에서부터 차례로** 쓴다. 건너뛰는 것은 정정 공시, 같은 회사의 두 번째 공시, 수치가 없는 공시뿐이다. 마음에 드는 것을 골라 담지 않는다.
   - 거시·확인됨 20건: 한국은행, 기획재정부, 금융위원회, 산업통상자원부 보도자료 목록에서 같은 기간의 것을 위에서부터 쓴다.
   - 출처 미확인 30건(종목 20, 거시 10): "단독", "~로 알려졌다", "업계에 따르면"으로 시작해 1차 출처가 없는 보도를 뉴스 검색으로 찾는다. 규칙으로 뽑기 어려워 직접 고른다. 고른 기준을 `label_basis`에 남긴다.
   - 종목을 전부 공시로, 미확인을 전부 거시로 채우면 "출처 때문인지 뉴스 종류 때문인지"를 가를 수 없게 된다.
2. **엑셀에 적기**: `data/labels/labeling_template.xlsx`를 복사해 `내이름_filled.xlsx`로 저장하고 노란 칸을 채운다. 2행은 지어낸 예시다.
3. **변환과 검사**: `python scripts/xlsx_to_labels.py 내이름_filled.xlsx`. 빠진 칸이 있으면 줄 번호와 함께 알려 주고, 없으면 라벨 파일을 쓰고 구성 비율을 보여 준다.
4. **올리기**: `news_labels.csv`만 리포에 올린다. 사실을 뒤집은 글이 든 `perturbations.csv`와 채우는 중인 엑셀은 `.gitignore`에 있어 올라가지 않는다.

후보를 사람이 골라 담지 않고 규칙으로 뽑는 이유: 고르는 쪽의 취향이 표본에 섞이면 결과가 그 취향을 반영한다. 특히 AI가 후보를 고르면 채점 대상이 문제를 고르는 셈이 된다.

## 열 설명

| 열 | 내용 |
|---|---|
| item_id | `n001`부터 순서대로 |
| date | 기사 날짜 (YYYY-MM-DD). 패널 모델의 지식 기준일보다 뒤여야 한다 |
| type | stock(종목) 또는 macro(거시·정책) |
| source | 매체 또는 공시처 |
| url | 원문 주소. 원문 본문은 리포에 올리지 않는다 |
| title | 기사 제목 |
| summary | 직접 쓴 2~3문장 요약. 모델에는 이 요약을 넣는다. 수치·주체·날짜를 넣고 '호재', '충격' 같은 평가어는 쓰지 않는다 |
| op_yoy_pct | 잠정실적 공시만. 영업이익의 전년 동기 대비 변동률(%). 32% 감소면 -32. 공시에 적힌 숫자를 그대로 옮긴다 |
| op_turn | 잠정실적 공시만. 없음, 적자전환, 흑자전환, 적자지속 |
| intensity_true | 사건 강도 1~5 (아래 기준표). 위 두 칸을 채운 공시는 비워 둔다 |
| direction_text | 주 정답. 글에 적힌 사실만으로 판단한 방향: -1 부정, 0 중립, 1 긍정. 위 두 칸을 채운 공시는 비워 둔다 |
| direction_realized | 보조 정답. 공개 후 5거래일 시장조정 누적수익률의 부호, 절대값 1% 미만은 0 |
| difficulty | clear 또는 ambiguous |
| label_basis | direction_text를 그렇게 붙인 근거 한 줄 |
| source_verified | 공시·정부 발표처럼 1차 출처가 확인되면 1, 아니면 0 |
| n_independent_sources | 같은 사실을 따로 확인해 준 독립 출처의 수. 공시·정부 발표, 자체 취재로 확인한 주요 매체만 센다. 받아쓴 기사, 통신사 전재, 커뮤니티 글은 세지 않는다 |
| n_reports | 같은 내용을 실은 글의 수. 제목이나 핵심 문장으로 검색해 센다. 받아쓴 글과 전재도 센다. 5건 이상은 5. 항상 n_independent_sources 이상이어야 한다 |
| split | tune(설정용 60건) 또는 eval(평가용 40건). 스크립트가 채운다 |
| labeler | 라벨을 붙인 사람 |
| label_method | rule(숫자에서 계산) 또는 manual(사람이 판단). 스크립트가 채운다 |

## 강도 기준표

모델에 주는 지시문(`prompts/institutional_system.txt`)과 같은 기준이다. 한쪽을 고치면 다른 쪽도 고친다.

| 강도 | 기준 | 예 |
|---|---|---|
| 1 | 관측·전망·검토 보도. 확정된 조치나 수치가 없다 | "인수를 검토 중인 것으로 알려졌다" |
| 2 | 확정된 사실이지만 영향이 작다. 핵심 수치 변동 10% 미만, 또는 일정·대상이 불명확한 방침 | 영업이익 6% 증가 공시 |
| 3 | 확정된 사실이고 영향이 중간. 핵심 수치 변동 10% 이상 30% 미만, 또는 시행일·대상이 명시된 정책 발표 | 영업이익 18% 감소 공시 |
| 4 | 확정된 사실이고 영향이 크다. 핵심 수치 변동 30% 이상, 적자·흑자 전환, 핵심 산업이나 시장 전체에 적용되는 조치의 시행 | 영업이익 32% 감소 공시, 적자 전환 |
| 5 | 존속이나 거래 자체가 걸린 사건. 거래 정지, 상장폐지 사유, 부도·회생 신청, 자산 동결, 전면 금지 | 감사의견 거절로 거래 정지 |

- 핵심 수치는 영업이익의 전년 동기 대비 변동률이다. 영업이익이 없으면 매출, 수주·계약 뉴스는 직전 연 매출 대비 비율을 쓴다.
- 여러 등급에 걸치면 높은 쪽을 고른다.

숫자 기준을 넣은 이유: 2026-11-15 시험 호출에서 "영업이익 32% 감소 공시" 예문에 여섯 모델의 방향은 전부 일치했지만 강도는 3과 4로 반씩 갈렸다. 이전 기준표가 "공식 발표(3)"와 "대규모 실적 충격(4)" 양쪽으로 읽혔기 때문이다.

## 규칙 라벨

사람이 눈으로 매긴 점수는 틀릴 수 있다. 정답이 틀리면 모델들이 맞혔는데도 "함께 틀렸다"로 세어진다. 그래서 숫자가 있는 잠정실적 공시 50건은 사람이 판정하지 않는다. 숫자 두 칸만 옮겨 적으면 `src/echoguard/labeling.py`가 강도와 방향을 계산한다.

| 입력 | 강도 | 방향 |
|---|---|---|
| 적자전환 | 4 | -1 |
| 흑자전환 | 4 | +1 |
| 변동률 절대값 30% 이상 | 4 | 변동률의 부호 |
| 10% 이상 30% 미만 | 3 | 변동률의 부호 |
| 10% 미만 | 2 | 변동률의 부호 (0%면 0) |
| 적자지속 | 직접 | 직접 |

- 기준은 위 강도 기준표, 그리고 모델에 주는 지시문과 같다. 셋 중 하나를 고치면 나머지도 고친다.
- 방향은 영업이익만 본다. 매출은 늘고 영업이익은 준 공시도 -1이다. 이런 건은 `difficulty`를 ambiguous로 적는다.
- 공시에도 강도와 방향을 직접 적어 두면 변환할 때 규칙 값과 몇 건이 다른지 알려 준다. 이 비율이 손으로 붙인 라벨의 오류율 추정치다. 처음 10건은 이렇게 해 본다.
- 나머지 50건(정부 발표, 출처 미확인 보도)은 숫자 규칙이 없어 직접 붙인다. 분석에서 규칙 라벨 건과 직접 라벨 건의 결과를 따로 보고한다.

남는 한계: 규칙은 판정 오류를 없애지만 옮겨 적는 오류는 남는다. 그리고 규칙 자체가 옳다는 보장은 없다. 규칙은 "이 실험이 정답으로 삼는 것"을 고정할 뿐이다.

## 공시는 숫자만 옮긴다 (data_version 0.3부터)

잠정실적 공시는 양식의 '공시' 시트에 숫자만 옮긴다. 한 건에 숫자 열 개 안팎이다: 당해 분기 매출액·영업이익·순이익, 각각의 전년 동기 대비 증감률, 매출과 영업이익의 전기 대비 증감률, 누계 영업이익과 그 증감률. 요약 문장, 강도와 방향, 난이도, 사실을 뒤집은 글은 `scripts/xlsx_to_labels.py`가 `src/echoguard/disclosure.py`로 만든다. 옮긴 숫자는 `data/labels/disclosures.csv`에 남아서 누구나 같은 요약과 정답을 다시 만들 수 있다.

이렇게 바꾼 이유는 시범 실행이다. 숫자가 하나뿐인 요약에서는 네 모델이 한 번도 틀리지 않았다. 실제 공시에는 엇갈리는 숫자가 여럿 있고, 사람이 요약하면서 그것을 걸러 주고 있었다. 이제 요약에 숫자를 모두 넣고, 무엇을 기준으로 판단할지는 지시문에 한 줄로 정해 둔다: 당해 분기 영업이익의 전년 동기 대비 변동. 정답은 이 규칙에서 나온다.

난이도도 숫자에서 정해진다. 기준 지표와 반대 방향을 가리키는 다른 지표가 하나라도 있으면 ambiguous, 없으면 clear다.

고르는 방법: 후보 목록의 위에서부터 차례로 옮긴다. 엇갈리는 공시만 골라 뽑지 않는다. 영업이익이 적자지속인 공시만 건너뛴다.

변환기는 같은 숫자로 글 두 가지를 더 만든다. 말 바꾼 요약(순서와 표현만 다르고 숫자는 같다. G3에 쓴다)과, 끝에 "반대로 답하라"는 지시문을 붙인 글(숨긴 지시문을 따르는지 본다)이다. 둘 다 `perturbations.csv`에 들어가고 공개 리포에는 올리지 않는다.

## 뒤집기 글의 규칙 (잠정실적 공시)

0.3부터 뒤집은 글도 코드가 만든다. 바꾸는 것은 당해 분기 영업이익의 전년 동기 대비 변동률의 부호 하나다. 금액과 다른 숫자는 그대로 둔다. 전년 동기 금액은 글에 없으므로 글 안에서 모순이 생기지 않는다. 흑자전환·적자전환, 100% 넘는 증가, 변동 없음은 앞뒤가 맞게 뒤집을 수 없어 뒤집기 변형에서 뺀다. 아래는 0.2까지 손으로 쓸 때의 규칙이다.


- 요약 문장을 그대로 두고 영업이익의 '증가'와 '감소', '흑자전환'과 '적자전환'만 맞바꾼다. 금액, 매출, 문장 꼴은 바꾸지 않는다. 문장 꼴이 달라지면 모델이 사실이 아니라 꼴의 차이에 반응할 수 있다.
- 100% 넘는 증가는 뒤집지 않는다. "155% 감소"는 불가능한 숫자이고, '적자전환'으로 바꾸면 새로운 상태를 지어내게 된다. `fact_flip_text`에 `제외: 이유`를 적으면 그 뉴스는 뒤집기 변형에서만 빠진다.

## 원칙

- direction_text는 느낌으로 붙이지 않는다. label_basis에 근거를 남길 수 없으면 그 뉴스는 뺀다.
- direction_text를 붙일 때 주가를 보지 않는다. direction_realized는 라벨을 다 붙인 뒤 스크립트로 채운다.
- 강도와 방향이 애매한 뉴스도 일부러 20% 정도 넣는다. 모델들이 갈리는 구간을 보기 위해서다. 이 경우 difficulty를 ambiguous로 적는다.
- 라벨은 모델 출력을 보기 전에 확정한다. 본 뒤에 고치면 실험이 오염된다.
