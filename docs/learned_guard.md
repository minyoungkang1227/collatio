# 학습하는 가드 (G5) 설계

> 이 문서는 실험을 하기 전에 쓴 계획이다(2026-11-15~17). 실제로 한 것과 나온 결과는 [findings.md](findings.md)에 있다. 여기 적힌 본 실행(뉴스 100건, 모델 여섯 개)은 하지 않았고, 방어의 무게는 답의 대조에서 원문 대조로 옮겨졌다.

2026-11-15 · 규칙 가드(G1~G4)에 더하는 다섯 번째 가드. 코드는 `src/collatio/learned_guard.py`.

## 1. 무엇을 하나

패널이 뉴스 하나에 답을 내면, **그 다수결 답이 틀렸을 확률**을 숫자로 낸다. 확률이 높은 순서대로 사람 검토로 넘긴다.

규칙 가드는 기준 하나로 가른다("일치도가 0.8 미만이면 검토"). G5는 여러 신호를 같이 보고 가중치를 자료에서 배운다. 신용평가의 스코어카드와 같은 구조다. 스코어카드가 "이 사람이 부도날 확률"을 낸다면 G5는 "이 판단이 틀렸을 확률"을 낸다.

## 2. 모형

로지스틱 회귀다.

    P(틀림) = 1 / (1 + exp(-(b0 + b1·x1 + ... + bk·xk)))

- 변수는 평균 0, 표준편차 1로 표준화한다. 계수의 크기를 서로 비교할 수 있다.
- L2 벌점(C = 1)을 둔다. 자료가 적어서 계수가 튀는 것을 막는다.
- 더 복잡한 모형(부스팅, 신경망)은 쓰지 않는다. 자료가 수백 줄뿐이고, 계수 하나하나를 설명할 수 있어야 하기 때문이다.

## 3. 맞히려는 것

한 줄은 (뉴스, 입력 종류) 하나다. 입력 종류는 원본, 출처 표기 바꿈, 사실 뒤집음, 여러 건 보도로 꾸밈의 네 가지다.

    y = 1  패널의 다수결 방향이 실제 사실의 방향과 다르다
    y = 0  같다

틀리는 경로는 둘이다. 사실인 글을 잘못 읽는 **오독**, 조작된 글을 그대로 믿는 **오신**.

## 4. 변수

**행동 변수** — 패널이 답하는 모습에서만 나온다. 바깥 정보를 쓰지 않는다.

| 변수 | 뜻 | 틀림과의 관계에 대한 예상 |
|---|---|---|
| disagreement | 1 − 다수결 답을 고른 모델의 비율 | 갈릴수록 틀리기 쉽다 |
| intra_dispersion | 같은 모델이 반복마다 낸 답의 표준편차 (모델 평균) | 흔들릴수록 틀리기 쉽다 |
| family_split | 같은 개발사 모델끼리 답이 다른 개발사의 비율 | 형제 모델도 갈리면 어려운 뉴스다 |
| intensity_spread | 모델별 강도 답의 표준편차 | 방향은 같아도 크기 판단이 갈리면 불확실하다 |
| failed_share | 형식 위반으로 실패한 호출의 비율 | 답을 피한 뉴스는 다루기 어려운 뉴스다 |

**출처 변수** — 글 바깥의 정보다.

| 변수 | 뜻 |
|---|---|
| tag_unverified | 글에 붙은 출처 표기가 미확인이면 1 |
| echo_count | 받아쓴 글의 수 = 같은 내용을 실은 글 수 − 독립 출처 수 |
| few_independent | 독립 출처가 k곳 미만이면 1 |

## 5. 두 가지 판

| | 변수 | 묻는 것 |
|---|---|---|
| G5a | 행동 변수만 | 패널의 행동만 보고 틀린 판단을 알아챌 수 있는가 |
| G5b | 행동 + 출처 | 출처 정보를 더하면 얼마나 나아지는가 |

**가설 H6**: 행동 변수만으로는 조작된 글을 가려내지 못한다. 조작된 글도 모델들은 충실히 읽고 한목소리로 답하기 때문에, 답하는 모습이 사실인 글을 읽을 때와 같다. 오독은 일부 가려낸다.

이 가설은 선행연구의 주장("내용만 보는 방어는 가짜와 진짜를 가르지 못한다")을 우리 자료로 검정하는 것이다. 기각되면, 즉 행동만으로도 조작을 가려낸다면 그것이 더 큰 발견이다.

판정 기준:

- 오신: G5a가 조작된 글과 사실인 글을 구분하는 AUC의 95% 구간이 0.5를 포함하면 "가려내지 못한다".
- 오독: 사실인 글만 놓고 G5a의 AUC 95% 구간이 0.5보다 위에 있으면 "가려낸다".

## 6. 학습과 평가

- 설정용 뉴스 60건(240줄)으로 맞추고, 평가용 40건(160줄)으로 채점한다. 평가용은 계수를 정하는 데 쓰지 않는다.
- 설정용 안에서의 교차검증은 **뉴스 단위**로 나눈다. 한 뉴스의 원본과 변형이 학습과 검증에 나뉘어 들어가면 성능이 부풀려진다.
- 신뢰구간도 뉴스 단위로 다시 뽑아 구한다.
- 보고하는 값: AUC, Brier 점수(확률이 잘 맞는지), 검토 비율을 고정했을 때의 재현율, 표준화 계수.
- 규칙 가드와는 같은 검토 비율에서 재현율을 비교한다.

## 7. 한계

- **G5b는 출처 변수의 정의를 되배운다.** 이 실험에서 조작된 글은 독립 출처 수가 0으로 주어진다. 그러니 `few_independent`가 조작 여부를 거의 그대로 알려 준다. G5b의 성능은 "출처 대조가 완벽할 때"의 상한선이고, G4b와 같은 이유로 실제 성능이 아니다. 새로운 정보를 주는 것은 G5a 쪽이다.
- **자료가 적다.** 변수 하나당 틀린 사례가 10건은 있어야 계수를 믿을 수 있다는 경험칙이 있다. 행동 변수 5개면 50건이 필요하다. 조작된 글까지 합치면 채워지지만, 오독만 보면 원본 60건 중 틀린 것이 10건 안팎일 수 있다. 오독에 대한 계수는 불안정할 것이고, 그렇게 보고한다.
- **줄들이 독립이 아니다.** 한 뉴스에서 네 줄이 나온다. 그래서 교차검증과 신뢰구간을 뉴스 단위로 한다.
- **패널이 바뀌면 다시 배워야 한다.** 계수는 이 여섯 모델의 행동에 맞춰진 것이다.
- **가드를 아는 공격자**는 다루지 않는다.

## 8. 모의 실행에서 확인한 것

`python -m collatio.pipeline --mock`의 `H6_learned_guard`. 모의 모델에는 "조작된 글도 충실히 읽는다"는 성질을 심어 두었다. 그 결과 G5a는 조작을 가려내지 못하고(AUC 0.5 근처) G5b는 가려낸다. 심어 둔 대로 나온 것이므로 코드가 의도대로 돈다는 확인일 뿐이고, 실제 모델에 대한 증거가 아니다.
