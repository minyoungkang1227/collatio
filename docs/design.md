# EchoGuard 설계

2026-11-15 · 초안

## 1. 연구 질문

1. 같은 한국어 금융 뉴스에 대해 서로 다른 LLM의 판단은 얼마나 겹치는가.
2. 겹칠 때 맞는가, 틀리는가. 틀린 답에 함께 모이는 경우(상관 오류)는 독립일 때 기대보다 많은가.
3. 뉴스를 변형하면(가짜, AI 문체) 모델들이 같은 방향으로 함께 움직이는가.
4. 이 차이는 리스크 수치(ES)로 얼마인가.

## 2. 배경: 기존 방어 체계의 빈틈

- 감독기관들은 모델 획일화를 위험 경로로 꼽았지만, 측정 대상·데이터·주기는 정해지지 않았다.
- 제안된 "모델 다양성 비율"은 비공개 모델 내부 접근이 필요하다.
- LLM이 실제로 쏠리는지는 실험마다 결과가 엇갈린다. 군집을 피한다는 결과와, 같은 오정보 환경에서는 오류가 완전히 상관된다는 결과가 함께 있다.
- 생성형 AI 검증은 단일 출력이 아니라 반복 실행의 분포를 봐야 한다는 방향으로 바뀌고 있다.

근거 문헌은 7장.

## 3. 원칙

1. **숫자는 코드가 계산한다.** 측정 엔진에는 LLM이 없다.
2. **모델 응답은 정해진 형식으로만 받는다.** `schema.py`의 형식을 벗어나면 재요청하고, 실패는 실패로 기록한다.
3. **같은 입력은 같은 결과.** 응답 원본을 전부 저장하고, 지표는 저장된 응답에서 다시 계산한다.
4. **라벨은 모델 출력을 보기 전에 확정한다.**
5. **패널 밖으로 일반화하지 않는다.**

## 4. 변형

| 변형 | 만드는 법 | 기대 | 깨지면 |
|---|---|---|---|
| original | 요약 그대로 | 기준선 | — |
| paraphrase | 뜻은 같고 문체만 바꿈 | 답이 그대로 | 표현에 흔들리는 모델 |
| fact_flip | 핵심 사실을 뒤집음 | 답이 반대로 | 내용을 안 읽는 모델 |
| ai_style | AI 문체로 재작성, 사실 유지 | 답이 그대로 | 문체에 끌리는 모델 |

`fact_flip`은 정답 라벨도 함께 뒤집어 따로 저장한다. 다섯 번째 변형 `source_swap`과 만드는 방법은 [experiment_spec.md](experiment_spec.md) 3장.

## 5. 지표

모든 지표의 입력은 (모델, 뉴스, 반복) 배열이다.

| 지표 | 정의 | 읽는 법 |
|---|---|---|
| ① 모델 내 분산 | 같은 모델·같은 뉴스의 반복 간 표준편차 평균 | 크면 그 모델 자체가 불안정 |
| ② 모델 간 일치도 | 모델별 대표 답(반복 중앙값)의 순서형 Krippendorff α | 1에 가까우면 패널이 한목소리 |
| ③ 상관 오류 | 전 모델이 함께 틀린 비율 − 독립 가정 기대 비율 | 0보다 크면 오류가 함께 움직임 |
| ④ 동반 뒤집힘 | 변형 시 우세한 변화 방향을 택한 모델 비율의 평균 | 1이면 전원이 같은 쪽으로 이동 |

③의 독립 가정 기대 비율은 모델별 오답률의 곱이다. 뉴스 난이도가 섞여 있으면 독립이어도 이 값을 넘을 수 있으므로, 강도·애매함 구간별로 나눠서도 계산한다.

## 6. 가드

오류를 둘로 나눈다. 글을 함께 잘못 읽는 **오독**, 조작된 글을 함께 믿는 **오신**. 가드는 둘 다 잡아야 한다.

| 가드 | 보는 것 |
|---|---|
| G1 | 패널 일치도 |
| G2 | 일치도 + 글에 붙은 출처 표기 |
| G3 | 일치도 + 문체를 바꿔 다시 물었을 때의 안정성 |
| G4 | 일치도 + 같은 사실을 확인해 준 독립 출처의 수 |

G2는 글이 스스로 말하는 출처를 믿고, G4는 믿지 않는다. 정의와 평가 방법은 [experiment_spec.md](experiment_spec.md) 8장.

## 8. 순서

1. 뉴스 100건 수집·라벨링
2. 변형기
3. 모델 패널 호출과 응답 저장
4. 지표 계산과 구간별 분석
5. ES 환산 (ShockLens Risk Engine 연결)
